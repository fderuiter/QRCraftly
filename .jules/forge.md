## 2025-05-11 - [UI Strategy Pattern for Enumerations]
**Context:** The `PatternModule.tsx` component used sequential `if` statements to switch between `QRStyle` enum values and render the appropriate UI elements. This approach increased cyclomatic complexity and violated the Open-Closed Principle, making it harder to maintain and extend as new styles are added.
**Decision:** Standardize on using a Strategy Pattern dictionary lookup (`Record<Enum, React.ReactElement>`) for mapping enumeration values to static JSX implementations, instead of using `switch` or sequential `if` statements. Since these UI elements do not rely on dynamic props, they can safely be evaluated once at the module level.
**Consequence:** Reduces cognitive load by extracting conditional rendering logic into a declarative map. Code is cleaner, strictly typed, and more scalable. Evaluating elements statically at the module level slightly increases initial parse time but minimizes render overhead, making it an acceptable trade-off for static elements.
